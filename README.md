# AIアバターチャット (Web / PWA)

古いスマートフォンでもサクサク快適に動作する、常時対話型AIアバターのWebアプリケーションです。

---

## 🌟 特徴と機能

1. **古いスマホでも超軽量・超高速**
   - 3Dモデルではなく、CSSのGPUアクセラレーションを最大限に活かした**2DベクターSVGアバター方式**を採用。
   - 古いローエンドAndroidや古いiPhoneでも、メモリ不足や発熱を起こさず、60fpsで滑らかに動作します。
2. **豊かなアニメーション & リップシンク**
   - **自然な呼吸モーション**: 胸と体の自然な上下運動と髪のゆらめき
   - **ランダム瞬き**: 自然な間隔での目パチ
   - **音声同期リップシンク**: 音声読み上げとリアルタイムに連動して口が開閉
   - **感情連動**: 返答内容に応じて5つの表情（通常・笑顔・驚き・困り・思考中）や漫符エフェクト（✨💧❓❗）が自動変化
3. **常時全画面 & 疑似画面オフ（待機モード）**
   - **PWA対応**: ホーム画面に追加するだけで、アドレスバーのない全画面ネイティブアプリとして起動。
   - **Screen Wake Lock**: アプリ起動中のOSスリープを防止。
   - **疑似画面オフ（🌙ボタン / 自動待機）**: 無操作時に画面を漆黒（#000000）にして有機EL消費電力を大幅カット。タップや音声で即座に画面復帰。
4. **キャラクターの詳細な性格付け**
   - システムプロンプトによる詳細な性格・口調・バックストーリー設定。
   - ワンタップで切り替えられる4つのプリセット（ツンデレ後輩、癒やしお姉さん、関西弁の友人、AI執事）。
   - 声の高さ（ピッチ）・話す速度のスライダー調整。
5. **キャラクターからの自律的な話しかけ（自律発話）**
   - 会話が途切れて静かな状態が続くと、現在の時間帯やこれまでの文脈を考慮して、アバターの方から自発的に声をかけてくれます。
   - 疑似スリープ中であっても、自律発話時に画面が点灯して話しかけてくれます。
6. **Gemini API & ブラウザ音声**
   - GoogleのGemini API（無料枠あり・超高速）を利用。
   - 音声認識（STT）と音声合成（TTS）はブラウザ標準（Web Speech API）を使用するため、追加の有料APIや重い外部ライブラリは一切不要。

## 🚀 起動方法

### 1. PC上でテスト起動する場合
本リポジトリのルートディレクトリで以下のコマンドを実行します：

```bash
npm start
```
起動すると、ブラウザ用URLが表示されます：
- `http://localhost:3000`

### 2. スマホから利用する方法（導入手順）

#### 方法A: 最も簡単な方法（GitHub Pages / Vercel / Netlifyなどの無料ホスティング）
スマホでマイクやPWAをフル活用するには、**HTTPS接続**が推奨されます。
このリポジトリのファイルをそのまま GitHub Pages や Vercel にアップロード（デプロイ）するだけで、無料のHTTPS URLが手に入ります。
1. スマホのブラウザ（ChromeまたはSafari）で発行されたURLを開く。
2. ブラウザのメニューから **「ホーム画面に追加」** または **「アプリをインストール」** をタップ。
3. ホーム画面に専用のアプリアイコンが追加され、タップするだけでアドレスバーのない全画面アプリとして起動します！

#### 方法B: ローカルWi-Fiでスマホから直接開く場合
1. PCで `npm start` を実行し、表示された `http://192.168.x.x:3000` を確認。
2. 同一Wi-Fiに接続したスマホのブラウザでそのURLを開く。
   > ※Android Chrome等でローカルIPのマイク使用がブロックされる場合は、Chromeのアドレスバーに `chrome://flags/#unsafely-treat-insecure-origin-as-secure` と入力し、お使いのURL（例: `http://192.168.1.10:3000`）を追加して「Enabled」に設定すると許可されます。

## ⚙️ 初期設定（Gemini APIキーの登録）

1. アプリ右上の **「設定（⚙️）」** ボタンをタップ。
2. **Gemini APIキー** の欄に、[Google AI Studio](https://aistudio.google.com/) で取得したAPIキー（無料）を入力。
3. お好みの「性格プリセット」や「声の高さ・速度」を選んで **「保存する」** をタップ。
4. 下部中央のマイクボタンを押して、「こんにちは！」と話しかけてみてください。

## 📁 ディレクトリ構成

```
aiアバターチャット/
├── index.html          # メインUI（全画面レイアウト・モーダル・吹き出し）
├── manifest.json       # PWA設定（スタンドアロン全画面、アプリアイコン定義）
├── sw.js               # Service Worker（オフラインキャッシュ対応）
├── server.js           # 外部依存ゼロのローカルHTTP配信サーバー
├── package.json        # プロジェクト設定
├── css/
│   ├── style.css       # 全体レイアウト、ダークモード、コントロールバー
│   └── avatar.css      # 2DアバターのCSSキーフレーム、表情、リップシンク
├── js/
│   ├── app.js          # メインコントローラ（対話フロー、自律発話タイマー）
│   ├── avatar.js       # アバター制御（表情、まばたき、口パク）
│   ├── gemini.js       # Gemini API連携（プロンプト送信、感情タグパース）
│   ├── speech.js       # 音声認識(STT)・音声合成(TTS)
│   ├── settings.js     # 性格設定・プリセット・localStorage保存
│   └── wakelock.js     # 画面点灯維持(Wake Lock)・疑似画面オフ制御
└── assets/
    └── icons/          # PWAアプリアイコン (SVG 192px / 512px)
```
